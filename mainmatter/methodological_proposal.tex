\section{Propuesta metodológica}

    Este proyecto tiene como finalidad asistir al mantenimiento mediante el uso de una aplicación de realidad aumentada que muestre instrucciones visuales, documentación propia de las máquinas así como su información básica y proporcione apoyo interactivo a los técnicos en formación.

    El proyecto se llevó a cabo en tres fases metodológicas las cuales desarrollan los objetivos específicos estableciendo una serie de actividades que buscan identificar los diferentes procedimientos y estrategias para su respectivo desarrollo, las cuales son:

    \begin{enumerate}

        \item Definición de requerimientos y restricciones.

        \item Desarrollo del aplicativo de realidad aumentada.
        
        \item Evaluación del aplicativo de realidad aumentada.
        
    \end{enumerate}
